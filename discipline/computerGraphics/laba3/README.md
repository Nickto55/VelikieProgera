# Лабораторная работа 3 - Компьютерная графика

## Описание
Программа для демонстрации аффинных преобразований 2D-фигур (четырёхугольников) с использованием библиотеки X11 для Linux.

## Требования
- Linux OS
- X11 development libraries (libx11-dev)
- g++ compiler
- make (опционально)

## Установка зависимостей

Для Ubuntu/Debian:
```bash
sudo apt-get install libx11-dev build-essential
```

Для Fedora/RHEL:
```bash
sudo dnf install libX11-devel gcc-c++ make
```

Для Arch Linux:
```bash
sudo pacman -S libx11 base-devel
```

## Компиляция

### Способ 1: Использование Makefile
```bash
make
```

### Способ 2: Использование CMake
```bash
mkdir build
cd build
cmake ..
make
```

### Способ 3: Прямая компиляция
```bash
g++ -Wall -Wextra -std=c++11 option_2.cpp -o option_2 -lX11
```

## Запуск
```bash
./option_2
```

## Управление
- **W** - сдвиг вверх
- **S** - сдвиг вниз
- **A** - сдвиг влево
- **D** - сдвиг вправо
- **Q** - поворот против часовой стрелки
- **E** - поворот по часовой стрелке
- **Z** - увеличение размера (масштабирование)
- **X** - уменьшение размера (масштабирование)
- **R** - сброс к начальной позиции
- **ESC** - выход из программы

## Очистка
```bash
make clean
```

## Возможные проблемы

### Программа не запускается
Убедитесь, что X-сервер запущен (обычно автоматически в графической среде):
```bash
echo $DISPLAY
```
Должно вывести что-то вроде `:0` или `:1`

### Ошибка "cannot open display"
Если запускаете через SSH, используйте X11 forwarding:
```bash
ssh -X user@host
```
